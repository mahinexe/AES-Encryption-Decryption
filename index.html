How AES Encryption Works+

AES — Advanced Encryption Standard.

GCM — Galois/Counter Mode, which provides authenticated encryption and detects tampering.

Nonce — A unique 12-byte value required for each encryption. It does not need to be secret and is stored with the ciphertext.

Key — The secret value required to encrypt and decrypt the data. It must remain secret.

Base64 — A text representation used to safely display binary encryption data.

Without the correct key and nonce, the ciphertext cannot normally be decrypted successfully.

AES-GCM authenticates the ciphertext, so decryption fails if the key, nonce, ciphertext, or authentication tag is incorrect or has been modified.
